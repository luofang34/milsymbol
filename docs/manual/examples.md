# Worked examples

Every snippet on this page is included directly from `examples/book.rs`, which
Cargo compiles. Building the book runs that example and writes the SVGs shown
below. The code and its picture therefore come from the same library build.
Use the [symbol lab](explorer.md) to change inputs and copy the resulting Rust call.

## A labelled infantry platoon

`15` selects MIL-STD-2525E Change 1 code meanings, `3` is friendly identity,
`10` is land units, `14` is a platoon, and `121100` is infantry.
The label is separate from the SIDC. The default rendering mode is standards;
`.strict()` rejects malformed or unavailable content.

```rust
# extern crate milsymbol;
{{#include ../../examples/book.rs:first_render}}
# Ok::<(), Box<dyn std::error::Error>>(())
```

![Infantry platoon generated by first_render](../images/book-first.svg)

## An input drawn inside a weather graphic

A tropopause-low symbol takes its height from `altitudeDepth`. MIL-STD-2525E
Change 1, Table M-II (printed pages 624–625), gives this height as three digits
above mean sea level "in hundreds of feet (or meters)" and does not say which.
The library draws the text as supplied and converts nothing, so `320` must
already be in the unit the reader expects. An empty value omits the value instead
of inserting an example number. `catalog::standards::Entry::input_field()`
identifies the field used by other variable graphics.

```rust
# extern crate milsymbol;
{{#include ../../examples/book.rs:weather_input}}
# Ok::<(), Box<dyn std::error::Error>>(())
```

![Tropopause low with a height value of 320](../images/book-weather.svg)

## APP-6 code meanings and display

Version `16` selects the APP-6(E) Version 2 code table. `Standard::App6` selects
its display rules. Both choices are explicit here: changing the display
standard alone does not turn a version `15` entity into a version `16` entity.


## Headquarters, movement and placement

The headquarters staff changes the map anchor. Place the symbol by subtracting
`symbol.anchor()` from its map position; centring its image would move the
staff foot away from the intended location. Direction is in degrees clockwise
from north. Text and leaders can enlarge the final image beyond `size`.

```rust
# extern crate milsymbol;
{{#include ../../examples/book.rs:direction_and_text}}
# Ok::<(), Box<dyn std::error::Error>>(())
```

![Headquarters, label and direction indicator](../images/book-hq.svg)

[Map placement](placement.md) explains scale and pixel density. This image is
generated by running `examples/map_marker.rs` during the book build; red dots
mark the requested map positions.

![Three symbols placed by their map anchors](../images/book-map.svg)

## Unfilled equipment with an outline

`fill(false)` removes the frame fill; the identity color applies to an
unfilled symbol. The white outline separates it from a busy map background.
The final image includes the extra margin needed for that outline.

